### Додано
- Перша версія `MonoBudget.js`: тижневий і місячний бюджет з EUR-рахунків Monobank.
- Віджети: малий, середній, великий; екран блокування — прямокутний, круглий, рядковий.
- Звіт у додатку: категорії зі змінами відносно минулого періоду, операції по днях, виключені операції.
- Синхронізація з дотриманням лімітів Monobank (1 запит / 60 с, ≤ 31 день, посторінково по 500).
- Інтерфейс українською та англійською.
- Тести на Node (`node:test`) із синтетичними фікстурами, smoke-тести API Scriptable, сканер секретів.
