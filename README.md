# MonoBudget для iOS

Тижневий і місячний бюджет витрат з **Monobank** у віджетах iPhone (домашній екран і екран блокування) через [Scriptable](https://scriptable.app/). Один файл JavaScript, без серверів і сторонніх залежностей.
